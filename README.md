📦 马院汇 (MASU Box)

“马院汇” 是一款专为校园生活打造的轻量化服务聚合应用，致力于将各类高频、零散的校园服务深度整合，为同学们带来高效、流畅的一站式使用体验。

✨ 核心模块与亮点介绍

1. 🌐 校园网一键通 (WLAN & Background Auth)

内嵌网页与无感后台登录：告别繁琐的网页反复跳转与手动认证。支持内嵌网页浏览与高效的后台登录机制，让校园网连接与认证一步到位。

2. 🗺️ 校园地图导航 (Campus Map Navigation)

多点多维度坐标映射：基于 Leaflet.js 深度定制的校园专属地图。通过精准的多点多维度坐标映射算法，将真实地理坐标与画布像素完美适配，实现轻量级、丝滑的校园精准导览。 

3. 🚀 聚合服务舱 (Shortcut Hub)

高频场景直达：高效聚合校园卡服务、微信/支付宝快捷扫码、共享单车一键开锁等日常刚需，真正做到即开即用、用完即走。

4. 📦 快捷身份码 (Express Pickup)

多平台一键出示：整合菜鸟、淘宝、拼多多等主流平台的快递取件身份码入口，免去多 App 切换的烦恼，取件高效便捷。

5. 📚 教务与拓展服务 (Academic & Tools)

学业助手：提供便捷的教务系统访问入口。

未来规划：目前采用轻量化入口设计，未来计划攻关并实现更具挑战性的智能课表自主导入功能，敬请期待。 

6. 🎨 现代 UI 与个性化体验 (Modern UI/UX)

原生级视觉享受：基于 Jetpack Compose 构建，支持全局深色/浅色模式（Dark/Light Theme）自由切换。

轻量账号体系：基于设备 ID 的极简设计，支持自定义个性化头像与 Emoji，兼顾隐私与专属感。
