马院汇 (MASU Box)

专为校园生活打造的轻量化服务聚合应用，致力于将各类高频、零散的校园服务深度整合，带来高效流畅的一站式体验。

蓝奏云高速下载 GitHub 源码仓库

🌐 校园网一键通

内嵌网页与无感后台登录：告别繁琐的网页反复跳转与手动认证。支持高效后台登录机制，让校园网连接一步到位。

🗺️ 校园地图导航

多点多维度坐标映射：基于 Leaflet.js 深度定制的校园专属地图，完美适配真实地理坐标与画布像素，实现轻量丝滑导览。

🚀 聚合服务舱

高频场景直达：高效聚合校园卡服务、快捷扫码、共享单车一键开锁等日常刚需，真正做到即开即用、用完即走。

📅 今日日程与待办

时间管理助手：内置日程与待办板块，帮助同学们高效规划每日安排、活动与个人琐事，告别遗忘与拖延。

📦 快捷身份码

多平台一键出示：整合主流平台的快递取件身份码入口，免去多 App 切换的烦恼，取件高效便捷。

🎨 现代 UI 与个性化

原生级视觉与隐私：基于 Jetpack Compose 构建，支持全局深色模式、设备 ID 极简账号体系及严密版本更新检查。
