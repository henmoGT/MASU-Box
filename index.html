告别繁琐切换与重复跳转，深度整合校园高频刚需，带给你高效、流畅的一站式使用体验。

蓝奏云高速下载 GitHub 源码仓库

🌐 校园网一键通

支持内嵌网页浏览与高效的无感后台登录机制，告别反复跳转与手动认证，让联网一步到位。

🗺️ 校园自定义地图

基于 Leaflet.js 深度定制，通过精准的多点多维度坐标映射算法，实现轻量级、丝滑的校园精准导览。

🚀 聚合服务舱

高效聚合校园卡服务、扫码、共享单车一键开锁等日常刚需，真正做到即开即用、用完即走。

📦 快捷身份码

整合淘宝, 菜鸟、拼多多等主流平台的快递取件身份码入口，免去多 App 切换烦恼，取件更高效。

📚 教务与拓展服务

提供便捷的教务系统访问入口。未来还将持续攻关智能课表自主导入功能，敬请期待。

🎨 现代 UI 与个性化

基于 Jetpack Compose 构建，支持全局深色/浅色模式切换与基于设备 ID 的极简专属账号体系。
